# Dino Rush

Endless runner 3D en el navegador: corre con tu dinosaurio por la jungla, el desierto, el glaciar, el volcán, el fondo marino, el pantano, el castillo del Conde, la montaña de la Gárgola, el cielo del Arcángel, el infierno del Demonio y el limbo de la Muerte.

**Jugar:** https://realnazan.github.io/dino-rush/

- Desliza (móvil) o usa las flechas (PC) para cambiar de carril, saltar y agacharte.
- **Multijugador en directo:** carrera o cooperativo con un código de sala.
- Se puede instalar como app desde el navegador y funciona sin conexión (salvo el multijugador).

Hecho con three.js (r128, licencia MIT).
